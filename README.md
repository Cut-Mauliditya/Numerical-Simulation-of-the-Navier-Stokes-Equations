# Numerical-Simulation-of-the-Navier-Stokes-Equations

This project derives the Navier-Stokes equations from first principles (Newton's Second Law -> RTT -> Cauchy -> Navier-Stokes) and solves them using the Chorin Projection Method and a Gauss-Seidel Poisson solver.
